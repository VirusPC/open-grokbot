# 写成一条学习笔记

1. 用一句话复述用户要记住的点。不确定时先问，不要编造。
2. 调用 `memory_write`：
   - `key` 用 `note:` 加一个短标题，例如 `note:durable-objects`
   - `value` 不超过两句，包含「是什么」和「在本仓的文件」
3. 写完后用一句话确认 key，并告诉用户可以在记忆面板里看到这条账本。
4. 如果只是在问概念、没有要求保存，不要写记忆。改用 `research` 或直接回答。

笔记是给以后的自己看的，不要写成大纲。
